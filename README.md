# NixOS: декларативная установка программ для 3D-печати

Учебный проект, посвящённый декларативному управлению программным обеспечением в NixOS. Практическая часть — комплект Blender, UltiMaker Cura и CHITUBOX Basic для установки на основе общей конфигурации.

Состав приложений, зависимости и параметры запуска определены в Nix-файлах. Версия nixpkgs закреплена в `flake.lock`, дистрибутивы проверяются по контрольным суммам. Программы устанавливаются вместе с библиотеками и пунктами запуска в меню рабочего стола.

## Состав программного комплекта

| Программа | Версия | Назначение | Команда запуска |
|---|---|---|---|
| Blender | 3.6.23 LTS | Создание и редактирование 3D-моделей | `blender` |
| UltiMaker Cura | 5.12.1 | Подготовка к печати пластиковой нитью | `cura` |
| CHITUBOX Basic | 2.3.1 | Подготовка к печати фотополимерной смолой | `chitubox` |

Для Blender и CHITUBOX подготовлены собственные рецепты. Cura использует готовый пакет `cura-appimage` из закреплённой версии nixpkgs.

## Установка

Требуется **установленная NixOS x86_64** с графическим окружением, доступом к интернету и правами `sudo`. Репозиторий закрытый: необходим авторизованный доступ к GitHub.

Получите проект, если каталог `~/nixos` ещё не существует:

```bash
cd ~
nix-shell -p git --run 'git clone https://github.com/AcronimD/nixos.git'
```

Далее выберите вариант, соответствующий конфигурации системы.

### Стандартная конфигурация

Для системы с обычным файлом `/etc/nixos/configuration.nix`:

```bash
sudo bash ~/nixos/workstation/scripts/install.sh
```

Скрипт создаёт резервную копию, подключает модуль приложений и применяет конфигурацию. Настройки дисков, загрузчика и пользователей сохраняются. После установки исходные настройки ОС находятся в `/etc/nixos/configuration.before-workstation.nix`.

### Конфигурация через flakes

Flake объединяет описание проекта в `flake.nix` и закреплённые зависимости в `flake.lock`. Если системная конфигурация уже использует flakes, подготовьте модуль без автоматического применения:

```bash
sudo bash ~/nixos/workstation/scripts/install.sh --prepare-only
```

Добавьте следующий путь в существующий список `imports` системного модуля, расположенного в `/etc/nixos`:

```nix
./workstation-apps/module.nix
```

Для модуля в другом каталоге скорректируйте относительный путь. Если конфигурация хранится в Git, добавьте новые Nix-файлы в его индекс. Затем примените свою конфигурацию, заменив `ИМЯ_ХОСТА` именем из `nixosConfigurations`:

```bash
sudo nixos-rebuild switch --flake /etc/nixos#ИМЯ_ХОСТА
```

### Запуск

Приложения доступны в меню рабочего стола; в KDE — в разделе «Графика». Также доступны команды `blender`, `cura` и `chitubox`. Профиль принтера, материал и параметры печати задаются пользователем.
